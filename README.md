
# Sales Performance Report 

## 📊 Overview
This repository contains an Excel workbook analyzing regional sales data across three product categories: **Electronics, Apparel, and Grocery**.  
The dataset includes structured records with details on **Region, Product Category, Units Sold, Revenue, and Discount Percent**.  
The workbook has been cleaned, summarized, and visualized with professional touches such as a cover sheet, frozen panes, protected formulas, and README documentation.

---

## 📂 Dataset Description
- **Columns:**
  - `Region` – East, West, North, South
  - `Product_Category` – Electronics, Apparel, Grocery
  - `Units_Sold` – Number of units sold
  - `Revenue` – Total revenue generated
  - `Discount_Percent` – Discount applied to the transaction

- **Granularity:** Regional sales records.  
- **Summary Tables:** Aggregated totals by Region and Product Category for easier comparison.  

---

## 🛠️ Tools & Techniques Used
- **Excel Tables** – Structured references for clean formulas.  
- **Formulas:**
  - `SUMIFS` for conditional aggregation (e.g., Electronics sales in East region).  
- **Charts:**
  - Bar Charts for regional comparisons.  
- **Formatting:**
  - Cover sheet with title, author, and date.  
  - Frozen panes for easy navigation.  
  - README notes for documentation.

## 📑 Structure of Workbook
1. **Cover Sheet** – Title, author, and report context.  
2. **Data Sheet** – Raw transactional data with frozen panes.  
3. **Summary Tables** – Aggregated totals by category and region.  
4. **Charts** – Visual comparisons of Units Sold vs Revenue.  
5. **README Sheet** – Documentation and usage notes.  

---

## 🚀 How to Use
- Add new sales rows to the **Data Sheet**.  
- Charts and summary formulas update automatically.  
- Do not overwrite locked formula cells.  
- Use the README sheet for guidance on structure and updates.
